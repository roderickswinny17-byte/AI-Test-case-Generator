# AI Test Case Generator

An AI-powered application that generates software test cases from requirement documents using Python and Ollama.

## Project Objectives

- Automate test case generation from natural-language software requirements.
- Use AI/NLP techniques to analyze requirements and identify relevant test scenarios.
- Generate positive, negative, boundary, and edge-case scenarios.
- Improve test coverage and reduce the possibility of missed test conditions.
- Reduce manual effort and repetitive work involved in test case design.
- Generate standardized and structured test cases.
- Export generated test cases into Excel for easy review and execution.
- Demonstrate the practical use of AI in the Software Testing Life Cycle (STLC).


## Tech Stack

- **Python** – Core programming language
- **OpenAI API / Ollama** – AI-powered test case generation
- **NLP** – Requirement analysis and text processing
- **Pandas** – Data processing and structuring
- **OpenPyXL** – Excel report generation
- **python-dotenv** – Environment variable management
- **VS Code** – Development environment
- **Git & GitHub** – Version control and source code management
- **venv** – Python virtual environment and dependency isolation
